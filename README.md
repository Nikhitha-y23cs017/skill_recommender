# 🎯 Skill Recommendation System Using Knowledge Graphs

## 📌 About the Project

The Skill Recommendation System is a knowledge graph-based application designed to help students identify the skills required for different career roles and discover relevant learning resources.

It connects career roles, required skills, courses, and learning resources through a knowledge graph to provide career-oriented learning recommendations.

## 🎯 Objectives

- Help students explore different IT career opportunities.
- Identify skills required for specific job roles.
- Recommend relevant learning resources and courses.
- Visualize relationships between careers, skills, and resources.
- Support students in planning their learning journey.

## ✨ Features

- **Career Exploration:** Explore different career roles.
- **Skill Recommendations:** Discover skills required for selected careers.
- **Learning Resources:** Find useful learning materials and courses.
- **Knowledge Graph Visualization:** Visualize connections between career roles, skills, and resources.
- **Interactive Interface:** Explore recommendations through a Streamlit application.

## 🛠️ Technologies Used

- Python
- Streamlit
- NetworkX
- PyVis
- Pandas
- CSV Datasets
